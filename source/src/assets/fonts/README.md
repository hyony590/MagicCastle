# 글꼴 파일(git에 올리지 않음)

이 폴더의 글꼴 파일은 라이선스상 **파일 자체의 재배포가 금지**되어 있어 git에서 뺐습니다(`source/.gitignore`).
파일이 없어도 게임은 돌아갑니다. 불러오는 순서는 [src/ui/text.ts](../../ui/text.ts)의 `loadStoryFont`에 있습니다.

| 글꼴 | 쓰는 곳 | 불러오는 순서 |
|---|---|---|
| 뚝딱감자체 | 프롤로그 대사 | ① 이 폴더의 `뚝딱감자체.ttf` → ② 눈누 공식 CDN(jsDelivr) → ③ Galmuri11 |

- 이 폴더에 파일을 넣어 두면 인터넷이 없어도 이 글꼴로 나옵니다. 파일은 **고치지 말고** 받은 이름 그대로 넣습니다.
- 라이선스: 임베딩(게임 안 탑재) 허용, 폰트 파일 수정·재배포·판매 금지.
