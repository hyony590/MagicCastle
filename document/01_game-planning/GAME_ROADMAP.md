# 마법의 성 게임 개발 로드맵

**현재 상태** 1단계 기능 명세서 작성 완료, 2단계 시작 대기

사용자가 **“2단계 시작하자”**라고 하면 2단계 리소스 명세를 작성한다. 각 단계의 결과물을 확인한 뒤, 사용자가 다음 단계의 시작을 요청하면 진행한다.

## 1단계 원작 분석과 기능 명세

첨부 캡처와 원작 플레이 영상을 바탕으로 화면 구성, 캐릭터 조작, 맵, 아이템, 몬스터, LIFE·LEVEL·SCORE와 클리어 규칙을 정리했다.

**결과물** [마법의 성 게임 기능 명세서](../../GAME_SPEC.md), [플레이 규칙 보완](GAMEPLAY_RULES.md), [스테이지 배치 명세](STAGE_LAYOUTS.md)

## 2단계 게임 리소스 목록 작성

[에셋 목록](../03_game-assets/ASSET_LIST.md)에 제작할 이미지 목록과 리소스 명세를 작성한다. 실제 이미지 제작은 3단계에서 시작한다.

| 분류 | 필요한 리소스 |
| --- | --- |
| 캐릭터 | 플레이어 캐릭터 3종 |
| 몬스터 | 악당 5종 |
| 아이템 | 기본 아이템, 특수 아이템 |
| 맵 | 돌벽, 발판, 사다리 |
| UI | LIFE, LEVEL, SCORE |
| 배경 | 게임 배경, 메뉴 배경 |

**결과물** 이미지 제작 목록 및 리소스 명세서

## 3단계 그래픽 제작

- 캐릭터 기본 이미지와 이동 애니메이션을 제작한다.
- 몬스터 이미지와 애니메이션을 제작한다.
- 아이템, 맵 타일, 배경, UI 이미지를 제작한다.
- 이미지 크기, 파일명, 투명 배경 여부의 기준을 정하고 적용한다.

**결과물** 게임에서 사용할 이미지 파일

## 4단계 개발 환경 구축

이 단계에서 코드 작성을 시작하고 프로젝트 구조와 게임 화면(Scene)을 구성한다.

| 기술 | 용도 |
| --- | --- |
| TypeScript | 개발 언어 |
| Phaser 3 | 게임 엔진 |
| Vite | 개발 환경 |
| Git | 버전 관리 |

**결과물** 실행 가능한 게임 프로젝트

## 5단계 기본 게임 구현

캐릭터를 조작해 맵을 이동하고 아이템을 획득할 수 있도록 다음 순서로 구현한다.

1. 게임 맵 출력
2. 캐릭터 출력
3. 좌우 이동
4. 사다리 이동
5. 발판 충돌 처리
6. 아이템 획득
7. 점수 및 생명 처리

**결과물** 캐릭터를 직접 조작할 수 있는 게임

## 6단계 게임 시스템 구현

- 몬스터 움직임 및 충돌
- 캐릭터 사망 및 부활
- 아이템 획득 조건
- LEVEL 증가 및 SCORE 계산
- 캐릭터 선택
- 게임 시작 및 종료

**결과물** 처음부터 끝까지 플레이할 수 있는 게임

## 7단계 원작 비교와 완성

- 캐릭터 움직임을 원작과 비교한다.
- 맵 배치와 크기, 아이템 위치와 획득 조건을 비교한다.
- 애니메이션 속도를 조정하고 효과음과 배경음악을 적용한다.
- 게임을 저장하고 배포한다.

**결과물** 웹에서 플레이할 수 있는 마법의 성
