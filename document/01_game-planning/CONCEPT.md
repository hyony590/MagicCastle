# 게임 콘셉트: 모찌의 마녀 부엌

숲속 마을의 '행복의 축제'에서 올해의 주인공으로 뽑힌 토끼 요리사 **모찌**가, 촌장의 부탁을 받고 만찬에 쓸 특별한 재료를 구하러 마녀의 성에 들어가는 이야기다. 성 안의 부엌 탑을 한 층씩 오르며 재료를 모으고, 꼭대기에서 마녀 쿠르르와 맞선다.

겉으로는 따뜻한 동화처럼 시작하지만, 축제의 진짜 의미(마녀에게 바칠 주인공을 고르는 의식)가 조금씩 드러나는 다크 판타지다. 이야기와 숨겨진 진실, 프롤로그 구성은 [STORY.md](STORY.md), 1부 뒤에 이어지는 공포 2부는 [PART2_HORROR.md](PART2_HORROR.md)에 있다.

## 분위기

- 따뜻한 파스텔 색의 픽셀 그림. 화면 갱신이 살짝 끊기는 옛날 플래시 게임 느낌을 유지한다.
- 배경은 밤의 부엌. 어두운 자줏빛 타일 벽에 나무 조리대 블록과 나무 사다리.
- 귀엽지만 쉽지 않은 게임. 몬스터는 뛰어넘을 수 없고 타이밍으로 피해야 한다.
- 프롤로그는 따뜻한 마을과 축제를 보여 주면서, 눈치챌 사람만 눈치채는 작은 틈(속삭임, 일제히 쳐다보는 눈, 촌장의 음흉한 얼굴, 모찌가 떠나자 내려가는 손)을 남긴다.

## 게임 요소 대응

| 게임 규칙 | 콘셉트 속 모습 |
| --- | --- |
| 기본 아이템 `gem` | 별사탕(설탕 결정) |
| 기본 아이템 `apple` | 딸기 |
| 기본 아이템 `coin` | 초코칩 쿠키 |
| 발판 블록 | 나무 조리대 블록 |

| 스피드 부츠 | 토끼 운동화. 죽거나 다음 레벨로 넘어갈 때까지 빠르게 달린다 |
