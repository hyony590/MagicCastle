# 게임 에셋 목록

콘셉트는 [모찌의 마녀 부엌](../01_game-planning/CONCEPT.md)을 따른다.

게임 그림은 코드 안의 픽셀 지도([source/src/art/sprites.ts](../../source/src/art/sprites.ts))로 그리고, 같은 그림을 PNG 파일로도 뽑아 두었다([source/src/assets/sprites/](../../source/src/assets/sprites)). 같은 키 이름의 PNG가 있으면 게임은 PNG를 쓰고, 없으면 코드 그림을 쓴다. 판정 크기는 그림과 따로 관리하므로 그림을 바꿔도 게임 규칙은 바뀌지 않는다.

PNG를 고칠 때는 아래 "픽셀 크기"(원본, 게임이 2배로 키움)나 "화면 크기"(그대로 씀) 중 하나로 그려 같은 이름으로 저장한다. 크기 표와 그리는 규칙은 [sprites/README.md](../../source/src/assets/sprites/README.md). 코드 그림을 고친 뒤 PNG로 다시 뽑으려면 `npm run export:sprites`(없는 파일만 만듦) 또는 `npm run export:sprites -- --force`(직접 고친 PNG도 덮어씀).

프롤로그 인물·배경 그림은 아직 코드 그림만 있다(아래 "프롤로그 그림").
