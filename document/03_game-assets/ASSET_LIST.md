# 게임 에셋 목록

콘셉트는 [모찌의 마녀 부엌](../01_game-planning/CONCEPT.md)을 따른다.

그림은 모두 코드 안의 픽셀 지도로 그린다([source/src/art/sprites.ts](../../source/src/art/sprites.ts)). 문자 하나가 픽셀 하나이고, 2배로 키워 화면에 그린다. 판정 크기는 그림과 따로 관리하므로 그림을 바꿔도 게임 규칙은 바뀌지 않는다.

PNG 파일로 바꿀 때는 같은 키 이름으로 이미지를 불러오면 된다. 방법은 [textures.ts](../../source/src/art/textures.ts) 주석에 있다. PNG는 아래 "화면 크기"로 만들거나, "픽셀 크기"로 만들고 2배로 키운다.
